# Kassim — démonstration

Prototype d’aide à la décision achats à 90 jours. Fournisseurs, contrats et scénarios fictifs ; aucun gain client ni cours futur démontré.

Cette version comprend la présentation du projet, les scénarios, les fournisseurs, le schéma et les questions pour un premier échange. Elle ne contient pas le dossier de stratégie et les recherches internes.

Site statique : `index.html` à la racine, ressources relatives, `.nojekyll` inclus. Aucun build ni installation requis. Cette démo et les sources de ce dépôt sont publiques. Le dossier de recherche complet est conservé séparément dans un dépôt privé.

Les polices locales Inter et Space Grotesk sont accompagnées de leurs licences OFL dans `assets/fonts/`.
